# Mark-XLIX - Jarvis AI Assistant

A Python-based conversational AI assistant powered by Gemini API with 112 OpenClaw skills.

## Features
- 🎤 Voice input/output support
- 🧠 Gemini AI integration with Ollama fallback
- 🛠️ 112+ modular OpenClaw skills
- ⚡ Fast response times

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```
